      THE COLLECTION / VERSIONED & BOUNDED

      A library you can inspect.

      Short source excerpts, linked to their original papers. Curator notes provide context and are always identified separately.

      THE METHOD / NO HIDDEN INFERENCE

      Make the work inspectable.

      The interface is an experiment in evidence sensitivity. What matters is whether the behavior, provenance, and eventual measurements can be checked.

      01 / WHAT RUNS TODAY

      A live lexical baseline.

      A question is tokenized and ranked against a curated excerpt collection using BM25. Selected passages become a cited, extractive brief. Removing a paper filters it out before the complete pipeline runs again.

      1. QuestionNew questions run locally.
      2. RetrieveRank the available excerpts.
      3. InspectOpen exact source text and metadata.
      4. StressRemove a paper; compare the rerun.

      02 / WHAT A SCORE MEANS

      Relevance is a narrow signal.

      A retrieval score estimates lexical relevance to your question. It is not a probability, truth confidence, citation verification, or a scientific verdict.

      Only unchanged, curated development examples can display sample claim relations. Current examples were AI-curated and await independent human adjudication. An edited or new question receives no automatic support or contradiction label.

      The collection uses short excerpts, often from abstracts. Full-paper qualifications may be absent. Inspect the original paper before relying on a finding.

      03 / RESEARCH EVALUATION

      Not measured yet.

      No held-out study has been completed.

      04 / THE NEXT RESEARCH GATE

      Earn the learned component.

      A CPU-trained relevance ranker is planned. It requires reviewed question–passage judgments, question-family-disjoint splits, frozen features, Python/browser parity, and comparison with the same BM25 candidate pool.

      The site checks for an optional model artifact. A missing, synthetic, invalid, or incompatible artifact leaves learned ranking visibly unavailable while the baseline remains usable. A valid reviewed-data pilot must be selected explicitly. Software checks do not establish model quality.

      05 / REPRODUCE A RUN

      Take the receipt.

      Every investigation can be exported as JSON or readable Markdown. The receipt records the question, corpus fingerprint, retrieval method, active excerpts, source exclusions, and limitations.

      Exports contain the active result. An excluded paper cannot remain in its evidence brief. Questions stay in memory until you explicitly download them.
