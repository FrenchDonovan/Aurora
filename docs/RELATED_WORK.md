# Aurora related work and novelty boundaries

Primary references checked on 2026-10-16. This is a bounded comparison, not an exhaustive prior-art search or a proof that nobody has built similar interactions. No paper's results have been reproduced by Aurora, and no external code, model or benchmark data has been imported.

| System | Exact primary reference | Overlap with Aurora | What Aurora reuses | Implemented direction / distinction | What remains unverified |
| --- | --- | --- | --- | --- | --- |
| ALCE | Gao, Yen, Yu and Chen. [Enabling Large Language Models to Generate Text with Citations, arXiv:2305.14627v2](https://arxiv.org/abs/2305.14627v2) | Citation quality, retrieval with cited answers, correctness as a separate dimension | Conceptual separation of answer quality and citation quality; one attributed seed excerpt only | Aurora's planned first release lets a visitor remove a paper and inspect reretrieval and an extractive brief without a model key | No ALCE benchmark run, no comparable generated-answer metrics, no citation-support classifier |
| ARES | Saad-Falcon, Khattab, Potts and Zaharia. | RAGChecker | Ru et al. [RAGChecker: A Fine-grained Framework for Diagnosing Retrieval-Augmented Generation, arXiv:2408.08067v2](https://arxiv.org/abs/2408.08067v2) | Diagnosing retrieval and response behavior rather than a single opaque score | Diagnostic framing only; no source code or metric outputs reused | Aurora exposes paper-exclusion sensitivity directly as a visitor interaction over a declared tiny corpus | No claim-level diagnostic benchmark, no claim that exclusion equals causal attribution, no measured human correlation |

| Pair-ID | Du. [What Would Fix This RAG Failure? Citation-grounded answers, scientific verification, RAG evaluation, retrieval diagnostics and public verification demos all have antecedents. A novel visual identity does not change that. The proposed portfolio contribution is the author's finished, inspectable implementation: a source-removal interaction, rights-aware versioned data, reproducible query receipts and an honestly evaluated intervention. Its value must be demonstrated by actual visitor behavior and experiments; the combination alone does not establish research novelty.

Use bounded public wording such as “Built an interactive evidence-sensitivity lab with reproducible retrieval runs.” Do not use “invented citation verification,” “first evidence stress test,” “hallucination-free,” “proves scientific claims,” or “outperforms existing RAG systems” without the separate research necessary to substantiate each claim. Before stronger novelty claims, search adjacent citation auditing, retrieval influence, deletion diagnostics and counterfactual RAG work and add overlapping systems here.
